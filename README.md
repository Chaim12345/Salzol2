# סל זול (Salzol)

אפליקציית אנדרואיד להשוואת מחירי סופרמרקטים בישראל בזמן אמת מתוך קובצי המחירים הרשמיים של הרשתות (תקן שקיפות מחירים).

## יכולות עיקריות
- **בחירת מיקום ורדיוס**: איתור סניפים קרובים לפי כתובת, שם עיר או GPS מתוך מאגר הסניפים (`directory.json`).
- **חיפוש מוצרים וברקודים**: חיפוש חופשי וסריקת ברקודים, כולל השוואת מחירים ליחידת משקל/נפח וסינון לפי כשרות ודיאטה.
- **מבצעים אמיתיים**: בדיקת מבצעים (כולל חישוב מחיר ליחידה ומחירי מועדון) והשוואה מול המחיר הזול ביותר ללא מבצע.
- **סל קניות והשוואת רשתות**: בניית סל, בדיקת הסניף המשתלם ביותר, פיצול קנייה חכם ומצב קנייה מסודר לפי מחלקות בסופר.
- **רשימות שמורות, מעקב שינויי מחיר והעשרת AI אופציונלית**: התראות ירידת מחיר, ייבוא רשימה מטקסט וסיווג מוצרים/בדיקת מבצעים עם ספק תואם OpenAI או Gemini.

## ארכיטקטורה
- **שפת פיתוח וממשק**: Kotlin + Jetpack Compose + Material 3 (פריסת RTL מלאה).
- **מנוע נתונים**: שכבת Kotlin מקומית (`il.salzol.core`) המממשת את הפורטלים הרשמיים של הרשתות, פענוח XML/GZ/ZIP, בניית קטלוג ואינדקס מוצרים.
